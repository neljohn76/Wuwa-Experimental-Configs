# 📦 AI Made Configs — SND855 Collection

Config generations for the **LG V50S ThinQ** (Snapdragon 855 / Adreno 640) produced with different AI assistants, kept for comparison and reference. Each AI folder is a snapshot of how that assistant approached the same brief — none are based on Arglax's Mobile-WuWa-Config files unless their own header says so.

## 📁 What's inside

| Folder | Origin | Contents |
|---|---|---|
| `ChatGPT/` | ChatGPT | 8 generations: *Balanced / PC Experience / Performance / Ultra Visuals* (New WuWa Configs), *LGV50S Profiles v1 & v2*, *Mengzhou v1.1 & v1.2*, *Lahai Roi Config* |
| `Claude AI/` | Claude | 1.0 — full 3-file set |
| `Mistral AI/` | Mistral | 1.0, Draft, and *Experimental Balanced Visuals v3.7* |
| `Vibe AI/` | Vibe (GLM) | The maintained tier family: **Performance / Balanced / Visual** — see its [README](./Vibe%20AI/README.md) |

> ℹ️ The original zip also carried empty `MediaTek/`, `Snapdragon/` and `Universal/` placeholders — no config files inside, so they are not recreated here.

## 🧹 Organization notes

- Trailing spaces in folder names ("Balanced ", "Ultra Visuals ") were removed.
- Generations were grouped per AI assistant and given readable folder names.
- File contents were preserved **exactly** as extracted — nothing was edited.
