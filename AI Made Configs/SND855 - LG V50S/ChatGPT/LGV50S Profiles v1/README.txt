Wuthering Waves v3.7 — LG V50S ThinQ (Snapdragon 855 / Adreno 640)
Fresh three-profile starter pack

PROFILES
- Performance/Engine.ini: prioritizes lower rendering load.
- Balanced/Engine.ini: recommended first test.
- UltraVisuals/Engine.ini: higher quality settings, higher GPU/memory load.

IMPORTANT
1. These are experimental Unreal Engine CVar presets, not tested on your exact game build/device.
2. Wuthering Waves may ignore, clamp, or override individual CVars. An .ini file cannot guarantee a visual change.
3. Back up the game's existing config files before editing. Do not overwrite unrelated game settings blindly.
4. Apply only ONE profile at a time. If you get a black screen, crashes, missing textures, or worse stutter, remove the added section/restore your backup.
5. Start with Balanced. Test the same route in Mengzhou for 10 minutes; then compare Performance and UltraVisuals.
6. Keep the game's FPS cap at 60 for initial stability testing. Do not force 120 FPS through unsupported variables.
7. Frame Generation: the official v3.7 notes do not list Snapdragon 855 as a supported mobile chipset. This pack does NOT spoof a different GPU or falsely enable Frame Generation. Device-profile spoofing may expose a menu option but does not guarantee correct frame generation and can cause instability. Treat it as a separate experiment, not part of the stable profiles.
8. A phone cooler helps with thermal headroom but cannot remove GPU/CPU limits. Avoid testing while charging if the phone becomes hot.

Install location varies by client/ROM/config method. Use the exact Engine.ini location that your current Wuthering Waves config workflow already uses. Keep a copy of the ld/ginal file.
